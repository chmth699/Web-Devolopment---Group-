# UniShare.lk 🎓

UniShare.lk is a simple website made for our Web Development group project.
It is a place where university students can find and share study materials
like notes, past papers, and other resources, all in one place.

## About the Project

This website was built to make studying easier for university students.
Instead of searching in many different places for notes and past papers,
students can visit UniShare.lk and find everything they need in one website.

## Pages in this Website

- **Home** – The landing page with a welcome message and a search box
- **Features** – Shows what the website can do (upload, download, comments, etc.)
- **Resources** – Where students can browse resources by category (Notes,Slides, Lab Reports, Videos, Past Papers)
- **About Us** – Information about the project and the team
- **Contact** – A contact form to reach out to us

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5 (for the navigation bar and layout)

## How to Run This Website

1. Download or clone this project folder.
2. Open the `Home.html` file in any web browser (Chrome, Edge, Firefox, etc.).
3. Use the navigation bar at the top to move between pages.

No installation or setup is needed. It is a static website, so it works by
just opening the HTML files in a browser.
